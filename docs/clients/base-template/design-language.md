# Design language — Camping Mer et Camargue

> DRAFT — requires human review. Generated by `/import-figma` on 2026-06-01.
> This document captures the visual patterns of the client's design, beyond the raw token values.
> Token values live in `tokens.json` and `figma-analysis.md`. This document captures HOW those values are applied.
> It is the reference for any block built without a Figma design.

## Layout patterns

- **Section spacing:** generous — standard sections use `py-20` (80px top/bottom); media+text sections use `py-16 md:py-24`
- **Content width:** constrained at 1440px — every block wraps content in `max-w-[1440px] mx-auto px-8`
- **Grid preference:** desktop-first responsive — 12-col grid for media+text blocks; 1→2→3 col for card grids (AccommodationGrid, ReviewGrid); 2→3→4 col for icon grids (AmenitiesGrid)
- **Asymmetry:** moderate — MediaTextBlock alternates image-left / image-right; section headings are always centered

## Card style

- **Separation method:** shadow — `box-shadow: 0 2px 20px rgba(26,74,82,0.09)` (soft teal-tinted). No border on card containers.
- **Corners:** `rounded-none` — all cards, CTAs, and image containers use square corners. The `--radius` theme token exists for shadcn primitives only; it is deliberately NOT applied to block-level components.
- **Padding:** standard (`p-6`) for card body interiors
- **Hover:** none on cards — no scale, no shadow change, no border-color change on card hover. Only links inside cards have hover states.
- **Card background:** `bg-card` / `bg-background` (white). Never `bg-secondary` inside a card.

## Typography hierarchy

- **Eyebrow present:** yes — `text-xs uppercase tracking-[0.2em] text-accent` — used above h2 in every section header and in the hero
- **Section title:** h2, `font-semibold` (Playfair Display 600), no explicit size class in components (inherits from global h2 styles)
- **Accent divider bar:** `w-16 h-0.5 bg-accent` — appears after h2 in MediaTextBlock text column ONLY. Not used in standalone section headers (AccommodationGrid, AmenitiesGrid, ReviewGrid headings do NOT have a divider bar).
- **Body text:** `font-body` (Montserrat), `text-muted-foreground` (#676977), `leading-relaxed`, `style={{ fontSize: 15 }}` in MediaTextBlock; `style={{ fontSize: 14 }}` in card bodies
- **Typical pattern:** `eyebrow → h2` for section headings; `eyebrow → h2 → divider-bar → body[] → ctas` for MediaTextBlock text column
- **H1 treatment (hero):** `clamp(2.2rem, 5vw, 3.5rem)` + `lineHeight: 1.1` + `font-semibold` + white on primary overlay

## Interaction style

- **Animations:** subtle — `transition-opacity` and `transition-colors` on interactive elements only. No scroll animations, no parallax, no entry animations.
- **Transition duration:** not explicitly set — relies on Tailwind default (`150ms`)
- **Transition easing:** default (`ease`)
- **Hover on cards:** none — cards themselves have no hover state
- **Hover on links (inside cards):** `hover:text-accent transition-colors` — color shift from primary to accent
- **Hover on text links:** `hover:text-accent transition-colors` (primary CTAs inside cards); `hover:opacity-90 transition-opacity` (anchor CTA buttons)
- **CTA primary hover:** `hover:opacity-90 transition-opacity` — simple opacity dim, no scale, no background change
- **CTA outline/ghost hover:** `hover:opacity-80 transition-opacity` — same opacity pattern

## Visual density

- **Whitespace:** high — generous `py-20` section padding, `mb-12` before card grids, `mb-5` between heading and content
- **Image treatment:** mixed — hero is full-viewport with CSS overlay; MediaTextBlock uses half-width absolutely-positioned image within a min-height container; AccommodationCard uses fixed `height: 220px` image
- **Hero overlay style:** CSS gradient using `color-mix(in srgb, var(--primary) 65%, transparent)` — teal-tinted gradient that's darker at top and bottom, lighter in the middle. Not a flat dark overlay.
- **Image fit:** always `object-cover` within a fixed container. No `object-contain` usage.

## Component patterns observed

- **Primary CTA:** `inline-flex items-center px-8 py-3.5 text-sm font-bold bg-accent text-primary hover:opacity-90 transition-opacity` — square corners, accent background, primary text color. Note: hero uses accent as primary CTA background; MediaTextBlock uses `bg-primary text-primary-foreground` for the "primary" variant.
- **Secondary CTA (outline):** `border: "1.5px solid var(--primary)"` transparent background, `color: var(--primary)`, same padding as primary. Square corners.
- **Ghost CTA:** `text-primary underline underline-offset-4` with `text-sm hover:opacity-80`. No background, no border, reduced visual weight.
- **Icon usage:** lucide-react, `size={16}` in metadata rows, `size={26}` in icon grid tiles, `size={14}` in CTA arrows. Accent color for decorative icons, primary for interactive.
- **Icon tile pattern (AmenitiesGrid):** 64×64px circle `rounded-full bg-secondary flex items-center justify-center` — the circle uses `bg-secondary`, not `bg-accent`.
- **Internal card divider:** `borderBottom: "1px solid var(--border)"` + `pb-5 mb-5` — separates metadata row from CTA in AccommodationCard. Not a block-level separator.
- **Star rating:** stars use `fill="var(--accent)"` for filled, `fill="none" color="var(--border)"` for empty.
- **Section background alternation:** pages follow `bg-background → bg-secondary` alternation. On HomePage: Hero (primary overlay), MediaTextBlock (bg-background), AccommodationGrid (bg-background), AmenitiesGrid (bg-secondary), MediaTextBlock (bg-background), ReviewGrid (bg-secondary).
- **Footer background:** `#162830` (`--brand-dark`) — darker than `--primary` (#1a4a52). This is a unique value not in the main palette.
