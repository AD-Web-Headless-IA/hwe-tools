## Notes for @hwp/core-ui
- **Cleaner reference than prior clients.** Tokens are already semantic (shadcn-style `--primary`/`--accent`/`--muted` + a parallel `--brand-*` palette) and exposed as Tailwind utilities through `@theme inline`. This maps almost directly onto the HWP `TokensContract` — good candidate as the canonical structure for future clients.
- **`MediaTextBlock` is the model atomic block**: data-agnostic, fully prop-driven (image/eyebrow/heading/body[]/ctas[]/imagePosition/backgroundColor). Strong candidate for `@hwp/core-ui/base-blocks/MediaTextBlock`. Supports 3 CTA variants: `primary` (bg-primary square), `outline` (1.5px solid border), `ghost` (text underline).
- **`AccommodationGrid` + `ImgGallerySection`** are also clean prop-driven blocks — good base-block candidates.
- **Self-contained blocks** (`HeroSection`, `BookingWidget`, `AmenitiesGrid`, `ReviewGrid`, `SiteNavigation`, `SiteFooter`) hard-code their content. When porting to `@hwp/core-ui` these must be refactored to accept props/content schemas — content must NOT live inside the component (HWP is multi-tenant; see domain-model).
- **Zero border-radius on cards and CTAs** — cards (AccommodationCard, ReviewCard), CTAs, and containers all use square corners. The `--radius: 0.3125rem` in theme.css is for shadcn primitives but is NOT applied to block-level components. Override shadcn defaults when implementing.
- **Card shadow is teal-tinted, not neutral:** `0 2px 20px rgba(26,74,82,0.09)`. No border on card containers. Use `bg-card` (white) as card background.
- **Accent bar divider**: `w-16 h-0.5 bg-accent` used in MediaTextBlock text column below h2. Not used in section-heading-only contexts (AccommodationGrid, AmenitiesGrid, ReviewGrid use eyebrow+h2 without a divider bar).
- **Sticky BookingWidget pattern**: sibling of hero `<section>` (not a child), `sticky top-[72px] md:top-[112px] z-[100]`, `marginTop: -40` to visually straddle the hero bottom edge. This is a layout-level concern, not a block prop.
- **Section background alternation**: `bg-background` (white) and `bg-secondary` (`#e4f3f5`) alternate for visual rhythm. AmenitiesGrid and ReviewGrid use `bg-secondary`; MediaTextBlock takes `backgroundColor` as a prop.
- **Routing differs from HWP target.** Reference is Vite + react-router SPA; HWP target is Next.js 14 with `[locale]` routing. The page→blocks composition pattern maps well onto HWP client compositions.
- **Inline sections in `LeCampingPage`** (page-hero, intro-split) are not yet extracted as components — classify in Phase 1 (block vs composition).
- `.dark` theme exists but is generic oklch greys, not brand-tuned — treat as not-designed-yet, ignore for token extraction.
- Two icon libraries in deps (lucide-react + MUI icons); usage seen is lucide-react only. MUI/Emotion is Figma-Make scaffolding noise.
